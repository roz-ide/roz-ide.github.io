Quick Start

Get Up and Running in 60 Seconds

Install RoZ IDE on any platform — Windows, macOS, or Linux. One command, no bloatware, no telemetry.

terminal — bash 
# Install via package manager
# macOS (Homebrew)
brew install roz-ide

# Windows (Winget)
winget install RoZ.IDE

# Linux (APT)
echo "deb https://repo.roz.dev stable main" | sudo tee /etc/apt/sources.list.d/roz.list
curl -fsSL https://repo.roz.dev/gpg.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/roz.gpg
sudo apt update && sudo apt install roz-ide

# Or download the binary directly
curl -L https://download.roz.dev/latest -o roz-ide.tar.gz
